# Audio sources and licensing record

All effects added in this release are synthesized by the delivered src/systems/audio.ts using Web Audio oscillators, generated noise, filters and gain envelopes. No third-party sound files, recordings, downloads, sample libraries, attribution-only assets, paid assets or external audio services are used. Existing synthesized music is retained. Generation happens on the device after the user unlocks audio; music and effects have independent saved volume controls.

Effects: warning, falling rock, impact, guardian charge/roll anticipation, bubble, King awakening, waterfall and lava ambience. Existing jump/throw/splat/pickup/step/cut remain synthesized. Ambient proximity is computed from the actual cascade locations. No audio licence keys or new environment variables are required.
